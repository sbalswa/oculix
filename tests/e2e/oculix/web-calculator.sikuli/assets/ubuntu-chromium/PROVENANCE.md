# Ubuntu Chromium visual baselines

These images are element screenshots of the controls in
`tests/e2e/fixtures/web-calculator/index.html`. They were generated with
Chromium 141.0.7390.37 from
`mcr.microsoft.com/playwright:v1.56.1-noble`, using a 1280×1024 viewport and
device scale factor 1.

Each filename maps to the correspondingly named visible interaction in
`web-calculator.py`. The images belong only to capability
`ubuntu-chromium`; another operating system or browser requires its own
capability directory and hosted-runner validation.
